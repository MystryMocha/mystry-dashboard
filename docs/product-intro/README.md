# 界面导览

用几张截图快速看一遍面板的主要页面。各页面的字段和操作见 [使用指南](../user-guide.md)，第一次开服见 [分步教程](../tutorials.md)，面板能做和不能做的事见 [项目首页](../../README.zh-CN.md#使用边界)。

截图拍摄于 `0.2.0-preview.2`，使用默认的 Mystry 暗色主题。示例实例是一键部署的 Paper 26.3「生存服」和一个空实例；设置页的安装路径换成了示例路径。

## 登录

![登录页](screenshots/01-login.png)

第一次打开时，这里显示「初始化管理员」，需要填写启动器给出的初始化令牌；之后用管理员账号登录。右上角可以切换主题。

## 实例总览

![实例总览](screenshots/02-dashboard.png)

顶部是实例状态，以及主机 CPU、内存和数据盘空间。每张卡片是一个实例，可以直接启动或停止；底部的「⋮」（更多操作）里有重启、强制停止和删除。

## 一键部署

![一键部署](screenshots/03-deploy.png)

选择核心、游戏版本、Java 和内存，勾选 EULA 后开始部署。默认选中 Paper 和最新正式版；右侧是新手指引。

## 导入已有服务端

![从本机文件夹导入](screenshots/04-import.png)

把已有服务端复制到数据目录的 `imports` 下，在这里选择它，面板会复制出一个新实例；另一个 Tab 用来上传 ZIP 压缩包。

## 控制台

![控制台](screenshots/05-console.png)

实时显示服务端输出，底部输入命令后回车发送。刷新页面或断线后会自动重连，并先显示最近的历史输出。

## 文件管理

![文件管理](screenshots/06-files.png)

只显示当前实例目录里的文件，可以上传、下载、重命名、在线编辑文本文件和删除。

## 实例设置 & JVM

![实例设置](screenshots/07-settings.png)

修改名称、启动用的 jar、Java 运行时和 JVM 内存与优化方案。

## 手机和窄屏

![窄屏总览](screenshots/08-mobile.png)

窄屏上侧栏收进左上角的菜单，实例改为单列卡片。
