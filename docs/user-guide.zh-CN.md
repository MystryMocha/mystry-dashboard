# 使用指南

[English](user-guide.md) · **简体中文**

本文按页面介绍面板的功能与日常操作。初次使用请先阅读 [快速开始](getting-started.zh-CN.md)，开服的逐步演练见 [分步教程](tutorials.zh-CN.md)。

---

## 面板是做什么的？

Mystry Dashboard 运行在你的**本机**上，通过网页管理多个 Minecraft **服务端**（并不启动游戏客户端）。你可以下载或导入服务端、启动 Java 进程、查看日志、修改配置、管理文件。

每个实例的文件位于面板数据目录下的 `instances/<id>`，由面板自动分配，不可移至别处；面板也无法浏览电脑上的其他文件夹。数据目录的位置与结构见 [配置说明](configuration.zh-CN.md#数据目录)。

面板默认地址为 `http://127.0.0.1:3000`，仅监听本机，外网无法直接访问。

## 界面导览

界面参照 Apple 的设计风格：左侧为悬浮的半透明 **侧栏**，右侧为 **主内容区**；右上角的按钮组包含「任务中心」「语言」与「外观」。每个页面以大标题开头，向下滚动时标题收入顶部工具栏。

```
┌─────────────────┐                  [任务中心][语言][外观]
│ Mystry Dashboard│  大标题                        [主要操作]
│                 │  说明
│ 服务器          │  ───────────────────────────────────
│  [实例总览]     │  主内容（卡片 / 分组列表 / 控制台）
│  [当前工作台]   │
│ 部署与维护      │
│  [一键部署]     │
│  [导入服务端]   │  ┌ 底部悬浮操作栏（保存 / 开始部署）┐
│  [联机]         │  └─────────────────────────────┘
│  [本机环境]     │
│ 用户名          │
│  [设置][退出]   │
└─────────────────┘
```

| 侧栏入口 | 路由 | 作用 |
|----------|------|------|
| 实例总览 | `/` | 列出所有实例，可快捷启停 |
| 当前工作台 | `/instances/<实例ID>` | 进入实例后出现，指向当前查看的实例 |
| 一键部署 | `/deploy` | 从官方源下载并安装核心 |
| 导入服务端 | `/import` | 将上传的服务端文件夹或 zip，或 imports 中的文件夹，导入为实例 |
| 联机 | `/multiplayer` | 将实例的游戏端口开放给好友，可使用自己的 frp 服务器或虚拟局域网 |
| 本机环境 | `/nodes` | 查看本机的系统、CPU、内存与实例数量 |
| 面板设置（左下角的齿轮） | `/settings` | **这台设备**：语言与外观，仅对当前浏览器生效。**面板**：登录有效期、下载来源与「在其他设备上打开」，对所有登录的设备生效。**账号**：修改密码、退出登录。**运行信息**：版本、监听地址、数据目录、备份目录与配置文件位置，仅供查看；如需修改，请编辑配置文件后重启面板 |
| 任务中心（右上角） | — | 从右侧滑出，列出最近的部署与导入任务；离开部署页后仍持续更新，直至任务完成或失败。按钮上的数字为进行中的任务数，无任务进行时隐藏；已取消的任务显示为「已取消」 |
| 语言（右上角） | — | 选择 **自动 / English / 简体中文 / 繁體中文**；设为自动时跟随浏览器语言：繁体中文（台湾、香港、澳门）显示繁體中文，其他中文显示简体中文，其余语言显示英文。选择保存在当前浏览器，也可在登录页右上角或面板设置中切换 |
| 外观（右上角） | — | 选择 **自动 / 浅色 / 深色** 外观（自动即跟随系统）；选择保存在当前浏览器，面板设置中同样可改 |
| 退出登录（左下角） | — | 退出当前浏览器的登录；面板设置的「账号」一栏有相同按钮 |

实例详情页顶部有 **控制台 / 文件管理 / 参数配置 / 备份 / 实例设置** 五个标签。

平板宽度（1024 像素及以下）下，侧栏收入左上角的「打开导航菜单」；手机宽度（768 像素及以下）下，底部另有 **总览 / 部署 / 导入 / 联机 / 本机** 标签栏，弹窗改为自底部升起的面板。按 Escape 或点击遮罩即可关闭菜单、弹窗与任务中心。

> 从旧版本升级时，已保存的主题自动换算：Mystry 暗色/亮色 → 深色/浅色 + Mystry 粉，Codex → 绿色，Grok → 石墨。

## 登录与账号

首次通过启动器运行时，面板自动创建管理员 `admin` 及随机密码，并显示在启动窗口中；手动运行面板时须自行创建管理员，步骤见 [初始化管理员](getting-started.zh-CN.md#初始化管理员)。当前版本仅支持一个管理员，创建后无法再注册第二个账号。

### 日常登录

- 标题 **「登录面板」** → 输入账号和密码 → **「登录」**。
- 登录状态保存在当前浏览器，默认 12 小时后过期；过期或清除站点数据后须重新登录。有效期可自行调整，见 [登录有效期](#登录有效期)。
- 修改密码：点击左下角的齿轮进入 **面板设置**，在 **账号** 一栏点击 **「修改密码」**，输入当前密码与新密码（至少 12 个字符）。
- 修改密码后，其他浏览器与设备上的登录随即失效，须以新密码重新登录；修改密码的当前页面保持登录，已打开的控制台自动重连。

### 登录有效期

在 **面板设置** 页 **面板** 一栏的 **「登录有效期」** 中，选择登录后多久须重新输入密码：2 小时、12 小时（默认）、1 天、7 天、30 天或 **「不过期」**。选择即保存，无需重启：

- 延长后，本设备即刻按新时长计算；其他设备在下次登录后生效。
- 缩短后，已登录时长超过新时长的设备须重新登录。
- 选择「不过期」后，已登录的设备将一直保持登录，直至修改密码。已开启「在其他设备上打开」时，请谨慎使用。

### 在其他设备上打开面板

面板默认仅允许本机访问。如需从手机或另一台电脑打开，点击顶栏的 **其他设备**（手机宽度下为 **本机** 页的 **在其他设备上打开**）；**面板设置** 页的 **面板** 一栏亦有同一入口。

- **直接访问**：适用于手机与本机连接同一 Wi-Fi，或本机拥有公网 IP 的情况。点击 **开启**，用手机扫描弹窗中的二维码，或在浏览器中输入列出的网址。
  - 默认使用 HTTPS，证书由面板自行签发，浏览器首次访问时提示「不安全」：点击「高级」→「继续前往」（iPhone 上为「显示详细信息」→「访问此网站」）。如需跳过此提示，可关闭 **使用 HTTPS**，但连接将不再加密。
  - **网卡** 默认为「所有网卡」，也可只选其中一块；每块网卡下方注明其适用场景。
  - 开启 **只允许同一网段的设备** 后，仅与本机处于同一网络的设备可打开面板。
  - Windows 首次可能询问是否允许 Node.js 访问网络，请选择「允许」。面板部署在云服务器上时，还须在云平台安全组中放行面板端口（默认 3000）；填写 **公网 IP 或域名** 后，弹窗给出可从外部访问的网址。
- **虚拟组网**：适用于手机使用移动数据或处于其他网络，又不想开放端口的情况。
  - **面板自带**：点击 **开启**，面板即运行 EasyTier（首次使用前先下载）。在 Android 手机上安装同一版本的 EasyTier，点击 **显示加入信息**，将网络名、密钥与节点填入 App 并开启 DHCP；加入后扫描 **打开面板** 中的二维码，手机随即出现在 **已加入的设备** 中。iPhone 没有官方 EasyTier 客户端，请改用下一种方式。
  - **已装的组网软件**：电脑与手机装好同一组网软件（如 Tailscale）并登录同一账号后，在此选择其网卡并 **开启**。

不再需要时点击 **关闭此方式**，面板恢复为仅允许本机访问。通过 SSH 管理的服务器也可使用启动器命令：`remote on`、`remote off`、`remote status`、`remote https off`。

### 安全建议

- 使用强密码。面板可读写实例文件并启动进程，应视为高权限工具。
- 不要在公共电脑上保持登录。
- 不要将管理员密码、配置文件中的密钥与初始化令牌告知他人或提交到仓库。
- 怀疑密码泄露或他人登录了面板时，修改密码，或按 [忘记管理员密码](#忘记管理员密码) 重置，对方的登录随即失效。

## 实例总览

**作用**：集中查看所有服务器的状态，并完成日常操作。

标题下方的「本机」一栏显示主机 CPU、主机内存与数据盘剩余空间。其下每台服务器占一行：状态之后是一句说明（例如「可以进服了」「这个服务器需要 Java 21」「这个服务器选择的 Java 已不可用」），右侧为对应的下一步按钮（邀请玩家、打开实例设置、查看并同意 EULA、查看控制台），最右为启动或停止。列表右上角可切换「全部 / 运行中 / 异常」。运行中的服务器显示进程的 CPU 与实际内存占用，旁边的细条表示其相对「最大内存」（为 Java 设置的堆内存上限 `-Xmx`）的比例；实际占用通常略高于该上限，二者并非同一概念。尚无实例时，页面列出一键部署、导入服务端、创建空实例三种方式。首次采样显示「采集中…」，当前系统不支持的指标显示「暂不可用」；监测失败时保留旧值并标注可能过期，可点击「重试监测」。

| 列 / 区域 | 说明 |
|-----------|------|
| 名称 | 点击该行按钮以外的任意位置（行尾有箭头）即可进入实例详情 |
| 核心 | Paper、Fabric、Vanilla、Forge、NeoForge；自行上传的 jar 显示为「自定义 Jar」 |
| 版本 | Minecraft 版本号（自定义导入可能为 `-`） |
| 状态 | 彩色徽章（见下表），后附一句当前可做的操作 |
| 操作 | 需要时先列出下一步（邀请玩家、打开实例设置、查看并同意、查看控制台、去迁移），再列出当前可执行的启动/停止；重启、强制停止、删除收在「更多操作」中 |

实例状态与指标每 5 秒自动刷新，切换到其他标签页时暂停。页面右上角有 **一键部署**、**导入服务端** 与 **创建空实例**（用于自行上传 `server.jar`）；尚无实例时，这三项改列于页面中央。手机宽度下，一键部署与导入服务端位于底部标签栏，页面右上角仅保留「创建空实例」，「本机」一栏移至服务器列表下方。刷新失败时保留上次的数据，并提示可能已过期。

### 实例状态

| 界面显示 | 含义 | 你可做的 |
|----------|------|----------|
| 已停止 | 没有运行中的 Java 进程 | 可启动 |
| 启动中 | 进程正在启动 | 等待 |
| 运行中 | 服务端已启动 | 可进游戏、发控制台命令 |
| 停止中 | 正在结束进程 | 等待 |
| 已崩溃 | 进程异常退出 | 查看控制台日志排查 |
| ▲ 待迁移 | 旧版外部实例，尚未接管 | 见 [旧版外部实例接管](#旧版外部实例接管) |

**按钮逻辑**

- **启动**：仅在非「运行中」时可用。
- **停止**：仅在非「已停止」时可用。
- **重启**：先停止再启动，确认弹窗提示中断风险。在总览的「更多操作」中，除启动中、停止中外均可使用；实例详情页顶部仅在实例运行时显示。
- **强制停止**：当即结束进程，可能损坏世界，须确认；建议先尝试普通停止。仅在进程存活（启动中、运行中、停止中）时可用，位于「更多操作」中。
- **删除**：须先停止实例，并输入实例名称确认；将删除面板中的记录与该实例目录的全部文件，不可恢复。旧版外部目录不会被访问或删除。除总览的「更多操作」外，实例详情 **实例设置** 页底部也有「删除实例」。

## 一键部署（表单说明）

从 Mojang / Paper / Fabric / Forge / NeoForge 下载文件并创建实例。下载缓慢或无法连接时，可在 [下载来源](#下载来源) 切换为国内镜像。

| 字段 | 说明 |
|------|------|
| 实例名称 | 总览中显示的名称，默认为「我的服务器」 |
| 核心类型 | Paper / Fabric / Forge / NeoForge / Vanilla；默认选中推荐新手使用的 Paper |
| 游戏版本 | 选定核心后自动加载版本列表，并默认选中最新正式版 |
| Paper 构建版本（可选） | 仅限 Paper；留空则使用最新构建（优先稳定版） |
| Loader / Forge / NeoForge 版本（可选） | 模组加载器版本；Fabric 另有 Installer 版本。留空则使用最新稳定版 |
| JVM 设置 | 填写初始内存与最大内存，选择优化方案；高级区可填写附加参数，见 [JVM 配置器](#jvm-配置器) |
| Java 运行时 | 默认为「系统默认 Java」，也可点击「重新扫描」后选择其他已安装的 Java，见 [Java 运行时](#java-运行时) |
| Minecraft EULA | 默认不勾选；须勾选「我已阅读并同意 Minecraft EULA」方可开始部署，启动时写入 `eula=true` |

页面右侧的新手指引介绍各核心的适用场景，以及部署后的进服步骤。

点击 **「开始部署」** 后显示进度条与状态文字（下载、解压、安装等），完成后 **自动跳转** 至新实例页。

面板默认同一时间仅执行一个部署或导入任务，其余任务显示为「排队」，属正常现象，请勿重复提交；排队位置也已满时，页面提示稍后重试。单个任务运行超过 30 分钟即判定失败。以上限制可在 [配置说明](configuration.zh-CN.md) 中调整。

**Forge / NeoForge 提示**：面板下载并运行官方安装器，耗时可能较长，请勿关闭面板。

### JVM 配置器

一键部署、导入、创建空实例与实例设置共用同一配置器。基础界面并排填写初始内存（`Xms`）与最大内存（`Xmx`），初始内存下方有 2 / 4 / 6 GB、最大内存下方有 8 / 10 / 12 GB 常用档位（超出本机内存的档位不显示），旁边（空间较窄时在下方）选择优化方案。内存框右侧的小箭头（或在框内按 ↑ ↓）每次增减 1 GB。初始内存未手动修改时按优化方案自动取值，修改后不再跟随最大内存变化。「高级 JVM 参数」折叠区包含附加参数与最终参数预览；填写了附加参数或参数有误时自动展开。

- **兼容优先**：仅生成内存参数，初始内存自动取 1 GiB（最大内存更小时取最大内存）。
- **G1 均衡**：启用 G1、并行引用处理与 200 ms 暂停目标，仅在已识别 Java 8 / 17 / 21 / 25 时可选。切换至此方案时，初始内存自动设为与最大内存相同，此后随最大内存变化，直至手动修改。
- **Paper Aikar**：仅在 Paper 且已识别 Java 8 / 17 / 21 / 25 时可选，初始内存锁定为与最大内存相同；低于 6 GiB 时给出警告。界面同时显示冻结版本、复核日期与 PaperMC 官方来源。

推荐最大内存约为本机总内存的 25%，按 512 MiB 向下取整，通常介于 2 GiB 与 8 GiB 之间，并为系统预留至少 2 GiB；低内存机器可降至 1 GiB，无法读取内存时回退为 2 GiB。

资源偏高、Java 版本未验证与 Paper 内存不足仅为警告。以下情况将阻止保存：未闭合的引号、内存参数重复或 `Xms` 大于 `Xmx`、互相冲突的 GC 参数，以及由面板负责的启动参数（`-jar`、classpath、模块启动、`@argfile`、`nogui` 等）。

## 导入已有服务端（表单说明）

页面提供三种方式，均复制出一个新的托管实例，实例不会直接在原目录运行。

选定来源前，页面仅显示来源一栏。上传并检查完成（或在 imports 中选中可导入的文件夹）后，右侧（窄屏时在下方）出现 **导入设置**：实例名称、面板识别出的服务端（核心与版本）、将使用的 Java 与最大内存，以及 EULA 勾选框（服务端自带的 `eula.txt` 已同意时不显示勾选框，摘要中注明已同意）。核心类型、Minecraft 版本、Java 运行时与 JVM 设置收在 **修改设置** 中，识别结果无误时无需展开。Java 版本不符、无可用 Java、JVM 参数有错误或警告、`user_jvm_args.txt` 无法使用时，**修改设置** 自动展开；切换到其他来源时重新收起。Minecraft 版本尚未确定时（例如上传 ZIP，版本须在导入时识别），摘要提示无法确认 Java 是否合适，可在 **修改设置** 中填写版本。

### 上传文件夹

在浏览器中直接选择服务端所在的文件夹。服务端位于运行面板的电脑，或位于你打开面板网页的另一台电脑，均可使用此方式：

1. 在原控制台正常停止服务器，确认世界已保存完毕。运行中的服务器会占用 `session.lock` 等文件，浏览器无法读取。
2. 打开侧栏 **导入服务端 → 上传文件夹**，点击 **选择文件夹**，选择整个服务端所在的层级（其中有 `server.jar` 或 `run.bat`）；也可将文件夹直接拖入框内。浏览器询问是否将这些文件上传到该网站时，点击上传。
3. 点击 **上传并检查**。浏览器分批将文件发送给面板，进度条显示已发送的文件数，期间可随时点击 **取消上传**。全部上传后，面板检查启动文件并读取根目录的 `user_jvm_args.txt`，规则同下文「从 imports 文件夹复制」。
4. 核对 **导入设置** 中的实例名称与识别结果，如需调整，点击 **修改设置** 修改核心类型、版本、Java 或内存，然后点击 **确认设置并导入**。

- 面板仅接收文件内容及其在文件夹中的相对路径，无法获取也不记录该文件夹在你电脑上的位置；原文件夹不受改动。
- 上传的文件先存放在数据目录的 `uploads` 中，确认导入时整体移入新实例，不会重复占用空间。
- 已检查的文件夹保留 30 分钟，在同一浏览器标签页中刷新后可继续确认；取消、过期或面板重启时将其删除。上传中途刷新页面，须重新上传。
- 浏览器仅上传文件，空文件夹不会保留；服务端启动时会自行创建所需的空文件夹。
- 文件数与总大小的上限同「从 imports 文件夹复制」；数据盘空间不足时，开始时即提示。
- 某个文件无法读取时，页面会列出该文件，通常是因为原服务器仍在运行。
- 多数手机浏览器无法选择文件夹，因此不显示此选项；此时可上传 ZIP，或从 imports 文件夹复制。

### 从 imports 文件夹复制

适用于服务端已位于运行面板的电脑、但尚未由面板管理的情况，例如通过 SSH 管理的服务器（浏览器在另一台电脑上，无法选择服务器上的文件夹），或体积特别大的服务端。

此方式默认不在方式切换中，须在「上传文件夹」下方点击 **「改为从 imports 文件夹复制」** 切换；`imports` 中已有文件夹，或浏览器无法选择文件夹（例如手机）时，会直接列出。步骤：

1. 在原控制台正常停止服务器，确认世界已保存完毕。
2. 将完整的服务端目录复制到 `imports` 文件夹，每个服务端单独一个文件夹，直接置于 `imports` 下。页面显示该文件夹在面板电脑上的完整路径（默认为面板所在文件夹中的 `data/imports`），点击 **复制路径** 即可复制。不要只复制 jar，世界、插件、模组与配置须一并复制。服务端在你自己的电脑上且体积很大时，可用 SFTP 工具（如 WinSCP、FileZilla）或 rsync 传至该文件夹，中断后可续传；经浏览器上传文件夹无法续传。
3. 打开侧栏 **导入服务端 → 从 imports 文件夹复制**，在「imports 里的服务端」中选择该文件夹；刚复制的文件夹须先点击 **刷新**。每行列出面板识别的核心与版本、启动所用的 jar，以及是否有 `user_jvm_args.txt`；尚未识别启动文件的显示「导入时再检查」，无法导入的注明原因且不可选。
4. 若根目录有 `user_jvm_args.txt`，面板自动沿用其中的参数：摘要的内存一栏显示「来自 user_jvm_args.txt」，**修改设置** 中 JVM 设置上方提示「已检测到配置文件，已自动配置」。如不需要，在此处点击 **取消**，参数即恢复为沿用前的状态，之后仍可点击 **重新应用**。文件解析失败时不予沿用，并在提示中说明原因。切换到其他文件夹时，上一个文件夹带来的参数会被还原。
5. 核对 **导入设置** 中的实例名称与识别结果，如需调整可在 **修改设置** 中修改，然后点击 **复制并导入**。核心类型与版本按启动文件名自动填写（例如 `forge-1.12.2-….jar` 填为 Forge 与 1.12.2），识别有误时可手动修改；核心类型保持 **自动识别** 时，以面板的识别结果为准。
6. 等待任务完成并跳转至实例页，检查文件与配置后，再从面板启动。

> 原服务器运行期间不要复制。面板无法锁定外部进程，运行中复制可能导致世界数据不一致。

面板仅列出 `imports` 下的第一层文件夹，无法选择电脑上的其他位置。复制前检查以下各项：

- 文件夹中不含符号链接、目录联接、设备文件等特殊文件；
- 该文件夹不是另一个面板实例的目录（根目录有 `.mystry-instance.json`）；
- 文件数不超过 20 万、总大小不超过 100 GiB（可在 [配置说明](configuration.zh-CN.md) 中调整），且目标磁盘空间充足。

面板不会修改或删除原文件夹及 `imports` 中的副本；确认新实例运行正常后，可自行删除 `imports` 中的副本。

### 上传 ZIP

| 字段 | 说明 |
|------|------|
| 安装包（`.zip`） | 必选；默认最大 512 MiB，解压后的条目数与总大小另有上限 |
| 实例名称 | 预检成功后填写，同部署 |
| 核心类型 / Minecraft 版本 | 位于 **修改设置** 中，可选；用于实例展示与 Java 版本提示，启动文件仍由面板探测 |
| JVM 设置 | 位于 **修改设置** 中，使用统一配置器；ZIP 中有 `user_jvm_args.txt` 时自动沿用，可点击 **取消** |
| Java 运行时 | 位于 **修改设置** 中；默认使用系统默认 Java，也可选择面板探测到的其他 Java |
| Minecraft EULA | 原服务端的 `eula.txt` 已同意时不再显示此项，摘要中注明「已同意」，该文件由服务端自行读取，面板不作改动；否则默认不勾选，勾选后启动时写入 `eula=true` |

导入分两步：

1. 点击 **上传并检查**：面板检查 ZIP 的结构与大小，并读取根目录（或唯一顶层文件夹）中的 `user_jvm_args.txt`。
2. 核对 **导入设置**（必要时展开 **修改设置**）后点击 **确认设置并导入**，此时才开始后台导入。

预检结果保留 30 分钟。在同一浏览器标签页中刷新或离开后返回，可继续确认；也可点击取消，即刻删除上传的临时文件。过期或面板重启后须重新上传。

导入时，若 zip 中仅有一层根文件夹，将自动展平到实例根目录；面板自动找出服务端 jar，或现代 Forge / NeoForge 的启动参数文件。任务排队已满时页面提示稍后重试，预检结果仍保留，无需重新上传。

## 下载来源

在 **面板设置** 页 **面板** 一栏的 **「下载来源」** 中，可选择面板下载文件的来源，保存即生效，无需重启：

- **官方来源**（默认）：直接连接 Mojang、PaperMC、FabricMC、Forge、NeoForge 与 GitHub，不连接任何第三方镜像。
- **国内镜像**：Vanilla、Forge、NeoForge 与版本列表使用 [BMCLAPI](https://bmclapidoc.bangbang93.com/)，frp 与 EasyTier 使用公共 GitHub 镜像。部署 Vanilla 时仍从 Mojang 读取版本清单，因为镜像文件的校验值取自该清单。镜像失败时自动改用官方来源。

国内镜像由第三方运营，面板仅使用可核对校验值的文件；校验不符的文件将被丢弃，并改试下一个来源。

选择国内镜像后，以下内容仍从官方来源下载：

- Paper 与 Fabric 的服务端文件，因其没有可靠的镜像。
- Forge 与 NeoForge 安装器的部分文件，因此网络完全无法连接 Mojang 时，安装可能失败。
- 服务端首次启动时自行下载的文件（如 Fabric 的依赖）。

已在本地缓存的文件不会重新下载，切换来源对其无影响。

## Java 运行时

面板不接受手动填写的 Java 路径。各游戏版本所需的 Java 见 [分步教程：装好 Java](tutorials.zh-CN.md#1-装好-java)。

「一键部署」与导入页按游戏版本自动选择 Java：系统默认 Java 合适时使用它，否则选择已安装的推荐版本；手动改选后不再自动调整。在「一键部署」中，实际使用的 Java 不是推荐版本时无法点击「开始部署」，页面会说明所需版本。已有实例的「实例设置」不会自动更改已保存的 Java。

选择器下方一行显示实际将使用的 Java 的状态：选择了面板登记的某个 Java 时显示该 Java（例如「Java 21.0.5 可用」），保持「系统默认 Java」时显示系统默认 Java；实际使用的 Java 不是推荐版本时，其后附「推荐 Java N」。推荐版本未安装时，同一行另有 **「安装 Java N」** 按钮（Windows 与 Linux x64 上支持 Java 8、17、21、25）。点击后先弹出确认，注明下载来源与大致体积；下载期间，进度条右侧的 **「取消安装」** 可中止下载并删除未完成的文件。面板从 GitHub 下载 Eclipse Temurin JRE（下载来源为国内镜像时经 GitHub 镜像下载）；每个版本固定为指定的发行版，使用前按 SHA-256 校验。安装位置为数据目录的 `runtimes/java`，安装后加入 Java 列表并选中。下载作为任务运行，可在「任务中心」查看进度；失败时可切换下载来源，或使用「自己下载安装」链接。

面板默认使用其运行环境 PATH 中的 `java`，界面显示为「系统默认 Java」；可在同一环境中执行 `java -version` 查看其版本。

如需使用其他已安装的 Java，在「一键部署」、导入页（**修改设置** 中）或「实例设置」的 **Java 运行时** 处点击「重新扫描」。选项仅显示主版本，同一主版本安装了多个时才附上路径以示区分；鼠标悬停在下拉框上可查看所选 Java 的路径。面板仅在 `JAVA_HOME` 与常见安装目录中查找，并逐一运行验证。列表中标为「不可用」的条目表示最近一次探测未能找到它，须重新选择。每次启动实例及运行 Forge / NeoForge 安装器前，所选 Java 都会再次验证。

版本不匹配时，控制台通常出现 `UnsupportedClassVersionError`，或服务端无法启动。

## 实例详情

顶部显示实例名、核心、版本、状态，以及当前可执行的操作：已停止时为 **启动**；运行中为 **停止** 与 **重启**，**强制停止** 收在旁边的「更多操作」中。左上角的「‹ 实例总览」返回总览。

### 控制台

- 实时显示服务端的输出。
- **输入命令 + 回车** 即发送至服务端（与游戏内控制台一致）；下方「常用命令」可点击发送 `list`、`save-all` 等。已发送的命令以粗体白字（如 `> list`）记入日志，其后紧接服务端的回复。
- 连接断开或刷新页面后自动重连，并先显示最近的历史输出。
- 单条命令的长度与每分钟可发送的命令数均有上限，超出时页面会提示，见 [配置说明](configuration.zh-CN.md)。
- 若显示「登录已失效」或「控制台连接凭证无效」，请尝试 **退出登录再登录**。

### 文件管理

仅可操作当前实例根目录中的文件：

| 位置 | 操作 |
|------|------|
| 顶部左侧 | **‹** 返回上级目录；路径逐级显示，点击任意一级即可跳回 |
| 顶部右侧 | **刷新**、**新建文件夹**（弹窗输入名称）、**上传** 文件到当前目录 |
| 点击文件夹 / 文本文件 | 进入文件夹，或打开文件编辑 |
| 每一项右侧「…」 | **下载**（仅文件）、**编辑**（仅文本文件）、**重命名**、**删除** |

**编辑** 在弹窗中打开文件内容，点击 **保存** 写回磁盘；大文件与二进制文件不支持在线编辑。

路径相对于实例根目录。修改 `mods`、`plugins` 或世界数据前，建议 **先停服**。

下载由浏览器直接保存，大文件也不会占满页面内存；默认同时最多 4 个下载，繁忙时提示「下载繁忙，请稍后重试」。如需复制整个目录，请停服后用系统文件管理器操作实例目录。

删除文件或文件夹均须在弹窗中确认；删除文件夹将一并删除其中内容，弹窗显示路径并提示不可恢复。

### 参数配置

- 常用 `server.properties` 键按基础、多人和权限、世界、性能分组展示，开关类设置以开关切换；未收录的键保留在「高级选项」中。
- 通过底部悬浮栏的 **保存配置** 保存后，须 **重启实例** 方可生效（页面有说明）。
- 页面标记未保存的修改，离开页面或关闭标签页前会确认是否放弃。
- 与直接编辑 `server.properties` 文件等价。
- 1.13 及更早版本的服务端以数字保存难度与游戏模式；表单仍显示名称，保存时写回数字。
- 服务器简介等文本中的中文写入文件时转为 `\uXXXX`，新旧版本的服务端均可正确读取。此前已成乱码的简介无法自动恢复，须重新填写。

### 联机

如需让玩家加入此服务器，打开侧栏 **部署与维护** 中的 **联机**，先在左上角选择实例，再用旁边的分段控件在 **直接连接**、**虚拟局域网** 与 **frp 穿透** 之间切换。每次只显示一种方式，切换不会关闭其他方式中已保存的设置。服务器加载完世界后，实例控制台上方也会提示「服务器已启动，现在可以进服了」，点击 **邀请玩家** 即可直达此页；如不想再看到该提示，点击其末尾的 **×**（不再提示）。面板仅转发该实例的游戏端口，不会暴露管理页面，也无需填写任何程序路径。

页面右侧为 **指引** 栏，说明各穿透模式的区别，以及无法连接时应逐项检查的内容。熟悉后可点击 **×** 关闭，之后点击 **显示指引** 重新打开；该选择保存在当前浏览器。窄屏时，指引位于页面底部。

- **直接连接**：玩家直接连接本机地址，适用于玩家与本机连接同一 Wi-Fi 或路由器，或本机拥有公网地址的情况。页面直接显示 **同一网络的加入地址**，点击 **复制** 后发给玩家即可，无需安装或设置任何内容。
  - 此为内网地址：仅与本机连接同一路由器或 Wi-Fi 的玩家可用，其他网络的玩家无法通过它连接。地址下方提供 **改用虚拟局域网** 与 **填写公网地址** 两种替代方案。
  - 服务器首次启动时，Windows 可能询问是否允许 Java 访问网络，请选择「允许」。
  - 电脑有多个地址时，优先尝试以 `192.168` 开头的地址。
  - 本机拥有公网 IPv6 时，下方另有 **IPv6 加入地址**，异地玩家若同样拥有 IPv6，可直接用它加入；无法连接时，请在路由器中仅放行游戏端口，不要完全关闭路由器的 IPv6 防火墙。
  - 本机拥有公网 IP（云服务器、机房主机）时，点击加入地址下方的 **填写公网地址**，填入公网 IP 或域名后，页面给出 **公网加入地址**，指引栏另附一份检查清单；最常见的问题是云平台安全组未放行游戏端口。游戏端口与面板端口并非同一端口：玩家进服只需放行游戏端口。

- **虚拟局域网**：无需自备公网服务器。打开顶部的 **对玩家开放这个实例** 开关（即刻生效，无需另行保存），下方随即出现 **让玩家加入** 三步：复制或下载 **加入说明** 发给玩家；玩家按说明运行 EasyTier；玩家在 Minecraft 中连接步骤里显示的加入地址。EasyTier 未安装时，页面仅显示下载按钮，安装后才出现开关。
  - 在 Windows 上须以管理员身份启动面板，玩家也须以管理员身份运行命令，否则无法创建虚拟网卡。面板未以管理员身份运行时，页面在下载 EasyTier 之前即以「管理员身份：未获得」一行给出提示。在运行面板的电脑上打开页面时，可点击 **以管理员身份重启**，随后的确认框会说明重启的影响；点击 **重启面板**，再在 Windows 确认框中点「是」，面板即自动重启，页面随后自动刷新。在该确认框中保留勾选「以后启动面板时也以管理员身份运行」，启动器此后每次启动面板都会申请管理员权限；页面上的 **不再申请** 可将其关闭。从其他设备打开页面，或使用标准（非管理员）账号时，页面改为给出操作步骤：在运行面板的电脑上右键 `mdash.cmd`，选择「以管理员身份运行」，再在菜单中选择「重启面板」。无论哪种方式，重启都会停止正在运行的服务器，之后须重新启动。以管理员身份运行时，服务器及其中的插件、模组同样拥有管理员权限，请只安装信任的内容；在此期间，该行保持为「管理员身份：已获得」，并持续给出这一提示。在此之前，以及虚拟局域网出错时，页面不显示 **让玩家加入**，以免发出无法使用的加入说明。
  - 打洞失败时，流量经社区共享节点中转，并以网络密钥加密。
  - **中继节点**：默认使用由志愿者维护的社区共享节点，它们随时可能下线，也可能距你和玩家较远。可展开 **中继节点**，在「自己的中继节点」中每行填写一个自己的节点（例如 `tcp://relay.example.com:11010`），或取消勾选「同时使用社区共享节点」以仅使用自己的节点，然后点击 **保存中继节点**。修改节点后，须将新的加入说明重新发给玩家。
  - **直连端口**：面板另开一个直连端口（显示在页面底部），拥有 IPv6 或处于同一局域网的玩家可不经中转直接连接。
  - **Windows 防火墙**：面板自动添加放行规则，仅放行虚拟地址上的游戏端口与直连端口（直连端口规则仅对面板启动的 EasyTier 程序生效），虚拟局域网关闭时自动删除；面板异常退出遗留的规则，在下次启动时清除。如果你曾在 Windows 防火墙弹窗中阻止过 Java，须先在「Windows Defender 防火墙 → 高级设置 → 入站规则」中删除 Java 的阻止规则。
  - 加入说明包含网络密钥，任何获得它的人都能进入此虚拟局域网并连接游戏端口，切勿公开发布。
- **frp 穿透**：需自备一台 frp 服务器（地址、端口与令牌）。尚未添加 frp 服务器时，页面先显示添加表单。添加后选择服务器、穿透模式与端口，点击 **保存并开放**；此后通过顶部的 **对玩家开放这个实例** 开关打开或关闭，**穿透设置**（连同 **添加 frp 服务器**）收入折叠区。删除按钮位于服务器下拉框旁，删除的是当前选中的服务器。
  - 穿透模式为 **公网端口** 时，玩家在 Minecraft 多人游戏中直接添加页面上的加入地址，无需安装 frp。
  - **STCP 中转** / **XTCP 打洞**：按 **让玩家加入** 中的步骤，复制或下载 **玩家配置** 发给玩家。玩家用官方 frpc 运行后，连接自己电脑上的 `127.0.0.1` 与「玩家本机端口」。STCP 经 frp 服务器转发；XTCP 为点对点直连，延迟更低，但部分网络无法打通。该文件包含令牌，仅发给要加入的玩家。

若面板无法连接 GitHub、客户端下载失败，点击下载按钮下方的 **手动安装**，页面显示官方压缩包的文件名与 SHA-256：用任意设备从官方页面或镜像下载同名文件，再点击 **上传压缩包**。面板仅安装 SHA-256 一致的文件。

实例启动后联机才会开启。若游戏配置中的 `server-ip` 设为某块网卡的地址，须先清空，否则外部连接无法进入。

### 备份

**立即备份** 将整个实例目录打包为一份备份（含世界、配置、mods 与 plugins）。服务器运行时亦可备份：面板先暂停自动保存并将世界写入磁盘，打包完成后恢复自动保存，玩家无需下线；实例处于启动中或停止中时，须待其完成。

| 位置 | 操作 |
|------|------|
| 顶部右侧 | **刷新**、**上传备份**（此前下载的 `.tar.gz`，校验通过后才出现在列表中）、**立即备份** |
| 每一项右侧「…」 | **下载**、**还原**、**删除** |

**还原** 前须先停止服务器。还原将以备份替换实例目录中的全部文件，备份之后新增的文件会被删除；弹窗中的「先备份当前文件」默认勾选，会先自动生成一份「还原前自动备份」，误操作时可再还原回去。还原前会完整校验备份，文件损坏或被改动时不会改动实例目录。若备份时的服务端 jar 与当前不同（例如此后升级过版本），还原后面板中的服务端文件、核心类型与版本将一并恢复为备份时的值。

备份默认存放在数据目录的 `backups/` 下，可通过 `BACKUP_DIR` 改存到另一块磁盘，见 [配置说明](configuration.zh-CN.md#数据目录)。备份仅包含该实例的文件，不含账号与面板中的实例设置。删除实例时默认一并删除其备份；若取消勾选「同时删除该实例的备份」，备份将保留在 `backups/` 中，但不再显示于面板；整个面板的备份方法见 [备份与迁移](tutorials.zh-CN.md#教程-8备份与迁移)。

### 实例设置

| 字段 | 说明 |
|------|------|
| 名称 | 可改 |
| Jar 文件名 | 相对于实例目录，如 `server.jar`。Forge / NeoForge 实例此栏改为只读的「启动文件」，显示部署或导入时面板识别出的参数文件 |
| JVM 设置 | 使用统一配置器修改内存、预设与高级参数；修改后建议重启 |
| Minecraft EULA | 勾选后每次启动时将 `eula=true` 写入 `eula.txt`；不勾选时保留实例目录中原有的 `eula.txt`（导入的服务端可自带同意记录）。已勾选后取消勾选并保存，会将其改为 `eula=false` |
| 安装路径 | 只读，显示实例目录的完整路径；由面板分配，创建后不可修改 |
| Java 运行时 | 默认为「系统默认 Java」，也可选择面板探测到的其他 Java；支持重新扫描 |

点击 **保存设置** 后，页面显示「设置已保存」或失败原因；离开页面前同样会确认是否放弃未保存的修改。

页面底部的「危险操作」中为 **删除实例**：须先停止实例并输入实例名称确认，可选择是否一并删除备份。删除后返回总览。

## 数据存在哪里？

实例列表、账号与任务记录保存在数据目录的 `panel.db` 中，实例文件位于 `instances/<id>/`。完整结构及更改位置的方法见 [配置说明](configuration.zh-CN.md#数据目录)，备份方法见 [备份与迁移](tutorials.zh-CN.md#教程-8备份与迁移)。

删除实例将删除该实例目录的全部内容。面板不会访问或删除旧版外部目录。

---

## 旧版外部实例接管

旧版外部实例指数据库中仍记录旧目录、尚未迁入面板托管根目录的实例。面板不会访问旧目录，也不会自动迁移或删除它。

1. 停止该实例，并停止面板服务。
2. 用操作系统的复制工具，将旧外部目录完整复制到数据目录下的 `instances/<id>`。
3. 启动面板，进入对应实例（总览中显示「▲ 待迁移」），点击 **完成迁移**。
4. 接管成功后，实例才按面板托管目录处理；旧目录仍由你自行保留或管理。

若目标目录为空、不完整、ID 不对应或实例仍在运行，接管将失败。不要尝试在面板中通过文件页访问旧目录。

## 常见问题

### 部署或导入一直卡住

- 页面显示「排队」属正常状态，页面持续刷新，直至任务完成或失败。
- 检查本机能否访问外网（Mojang、Paper、Fabric、Forge 等）。在中国大陆可尝试将 [下载来源](#下载来源) 切换为国内镜像。
- 查看进度文字停在哪一步；Forge / NeoForge 的安装尤其慢。
- 任务中心显示失败原因；面板日志中可能有更详细的错误，可用启动器的 `logs` 命令查看。

### 启动后立即退出或「已崩溃」

先查看 **控制台** 上方是否有提示。面板可识别以下几种原因，并直接给出下一步：

- **还没同意 Minecraft EULA**：状态为「已停止」。点击提示中的 **同意并启动** 即可；也可在 **实例设置** 中勾选 Minecraft EULA。
- **Java 版本太新或太旧**：提示会注明该服务器所需的 Java 版本。点击 **下载 Java** 并安装后，打开 **实例设置**，点击 **重新扫描**，选中该 Java，保存后再启动。
- **之前选的 Java 已不可用**（已被卸载或移动）：启动前，总览与控制台上方即会提示。打开 **实例设置**，点击 **重新扫描**，重新选择一个 Java，保存后再启动。

若无提示：

1. 查看控制台最后几行错误。
2. 在 **实例设置** 中检查 Jar 文件名与 JVM 参数。
3. 确认所用 Java 可用且版本匹配，见 [Java 运行时](#java-运行时)。

### 游戏连不上服务器

- 服务端是否 **运行中** 且控制台已出现 `Done`。
- `server.properties` 中的 **server-port** 是否与游戏中填写的端口一致。
- 本机测试使用 `127.0.0.1`；局域网内使用主机的局域网 IP；云服务器使用公网 IP，并在安全组中放行游戏端口。
- 防火墙是否放行 Java 或该端口。
- 进服时提示不在白名单中：服务端开启了白名单（`white-list=true`）。在控制台执行 `whitelist add 玩家名` 将玩家加入名单，或在「参数配置」关闭「启用白名单」并重启。白名单开启而名单为空时，控制台上方与「联机」页均有提示。

### 提示「登录已失效」

- 重新 **登录**。
- 手动运行面板且初始化管理员失败时，确认填写的是当前配置文件中的 `SETUP_TOKEN`，且尚未创建过管理员。

### 导入 zip 失败

- 确认文件为 **zip** 且不超过 512 MiB；提示超出大小限制时，改用较小的压缩包或调高上限。
- 提示繁忙时，待当前上传结束后重试。
- 压缩包内是否包含服务端 jar（而非仅有客户端）。
- 压缩包内有指向包外路径的条目时，面板将拒绝导入。

### 忘记管理员密码

面板运行期间，在运行面板的电脑上执行 `reset-password` 命令：Windows 为 `.\mdash.cmd reset-password`；Linux 便携版为 `./mdash reset-password`，源码版为 `./mdash.sh reset-password`。Windows 上也可双击 `mdash.cmd`，在菜单中选择「重置管理员密码」；登录页附有同样的提示。窗口显示一个新的随机密码，仅显示一次。请直接在终端窗口中运行：输出被重定向到文件或经管道传出时，命令将拒绝执行，旧密码继续有效。登录后点击左下角的齿轮进入「面板设置」，点击「修改密码」改为自己的密码。

重置密码会使所有浏览器与设备上的登录失效，包括你正在使用的；重新打开面板，以新密码登录即可。

不使用启动器、手动运行面板时，此命令不可用。须停止面板后自行处理数据目录中 `panel.db` 的 `users` 表，或删除 `panel.db` 后重新初始化（实例注册信息将丢失，磁盘上的实例文件仍保留）。重新初始化时须重新配置 `SETUP_TOKEN`。
