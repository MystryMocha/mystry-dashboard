# 使用指南

[English](user-guide.md) · **简体中文**

本文按页面说明面板的功能和日常操作。第一次使用请先看 [快速开始](getting-started.zh-CN.md)，手把手的开服流程见 [分步教程](tutorials.zh-CN.md)。

---

## 面板是做什么的？

Mystry Dashboard 运行在你**本机**上：用网页管理多个 Minecraft **服务端**（不是启动游戏客户端）。你可以下载或导入服务端、启动 Java 进程、看日志、改配置、管文件。

每个实例的文件都放在面板数据目录下的 `instances/<id>`，由面板自动分配，不能改到别处，也不能浏览电脑上的其他文件夹。数据目录的位置和结构见 [配置说明](configuration.zh-CN.md#数据目录)。

面板默认地址是 `http://127.0.0.1:3000`，只监听本机，外网无法直接访问。

## 界面导览

界面参照 Apple 的设计风格：左侧是悬浮的半透明 **侧栏**，右侧是 **主内容区**；右上角的按钮组放着「任务中心」「语言」和「外观」。每个页面以大标题开头，向下滚动后标题会收进顶部工具栏。

```
┌─────────────────┐                  [任务中心][语言][外观]
│ Mystry Dashboard│  大标题                        [主要操作]
│                 │  说明
│ 服务器          │  ───────────────────────────────────
│  [实例总览]     │  主内容（卡片 / 分组列表 / 控制台）
│  [当前工作台]   │
│ 部署与维护      │
│  [一键部署]     │
│  [导入服务端]   │  ┌ 底部悬浮操作栏（保存 / 开始部署）┐
│  [联机]         │  └─────────────────────────────┘
│  [本机环境]     │
│ 用户名 [退出]   │
└─────────────────┘
```

| 侧栏入口 | 路由 | 作用 |
|----------|------|------|
| 实例总览 | `/` | 所有实例列表与快捷启停 |
| 当前工作台 | `/instances/<实例ID>` | 进入某个实例后出现，指向正在查看的实例 |
| 一键部署 | `/deploy` | 从官方源下载并安装核心 |
| 导入服务端 | `/import` | 上传服务端文件夹或 zip，或从 imports 文件夹复制成实例 |
| 联机 | `/multiplayer` | 把某个实例的游戏端口开放给朋友。可用自己的 frp 服务器，也可以开虚拟局域网 |
| 本机环境 | `/nodes` | 查看这台电脑的系统、CPU、内存与实例数量 |
| 任务中心（右上角） | — | 从右侧浮出最近的部署和导入任务；离开部署页后仍会更新，直到完成或失败 |
| 语言（右上角） | — | 选择 **自动 / English / 简体中文 / 繁體中文**；自动时按浏览器语言：繁体中文（台湾、香港、澳门）显示繁體中文，其他中文显示简体中文，其他语言显示英文。选择保存在本浏览器，登录页右上角也能切换 |
| 外观（右上角） | — | 选择 **自动 / 浅色 / 深色** 外观（自动跟随系统）；选择保存在本浏览器 |
| 退出登录 | — | 退出当前浏览器的登录 |

实例详情页顶部有 **控制台 / 文件管理 / 参数配置 / 备份 / 实例设置** 五个标签。

平板宽度（1024 像素及以下）时，侧栏收进左上角的「打开导航菜单」；手机宽度（768 像素及以下）时，底部还会出现 **总览 / 部署 / 导入 / 联机 / 本机** 标签栏，弹窗改为从底部升起的面板。按 Escape 或点遮罩可以关闭菜单、弹窗和任务中心。

> 从旧版本升级时，原来保存的主题会自动换算：Mystry 暗色/亮色 → 深色/浅色 + Mystry 粉，Codex → 绿色，Grok → 石墨。

## 登录与账号

用启动器第一次启动时，会自动创建管理员 `admin` 和一个随机密码，显示在启动窗口里；手动运行面板时要自己创建管理员。步骤见 [初始化管理员](getting-started.zh-CN.md#初始化管理员)。当前版本只能有一个管理员，创建后不能再注册第二个账号。

### 日常登录

- 标题 **「登录面板」** → 输入账号密码 → **「登录」**。
- 登录状态保存在当前浏览器，默认 12 小时后过期，过期或清除站点数据后需要重新登录。多久过期可以自己改，见 [登录有效期](#登录有效期)。
- 修改密码：点左下角的钥匙图标，输入当前密码和新密码（至少 12 个字符）。
- 修改密码后，其他浏览器和设备上的登录会立即失效，需要用新密码重新登录；修改密码的这个页面保持登录，打开着的控制台会自动重连。

### 登录有效期

在 **本机环境** 页的 **「登录」** 一栏选择登录后多久需要重新输入密码：2 小时、12 小时（默认）、1 天、7 天、30 天或 **「不过期」**。选了就保存，不需要重启：

- 改长后，这台设备马上按新时长计算；其他设备下次登录后生效。
- 改短后，登录已超过新时长的设备需要重新登录。
- 选「不过期」后，登录过的设备会一直保持登录，直到修改密码。开启了「在其他设备上打开」时请谨慎使用。

### 在其他设备上打开面板

面板默认只允许这台电脑访问。想用手机或另一台电脑打开时，点顶栏的 **其他设备**（手机宽度下在 **本机** 页的 **在其他设备上打开**）。

- **直接访问**：手机和这台电脑在同一个 Wi-Fi，或者这台电脑有公网 IP 时用。点 **开启**，用手机扫弹窗里的二维码，或在浏览器里输入列出的网址。
  - 默认使用 HTTPS，证书是面板自己签发的，浏览器第一次会提示「不安全」：点「高级」→「继续前往」（iPhone 上是「显示详细信息」→「访问此网站」）。不想看到这个提示，可以关掉 **使用 HTTPS**，连接就不再加密。
  - **网卡** 默认是「所有网卡」，也可以只选一块；每块网卡下面写着它适合哪种情况。
  - **只允许同一网段的设备** 开启后，只有和这台电脑在同一个网络里的设备能打开面板。
  - Windows 第一次可能弹窗询问是否允许 Node.js 访问网络，请选「允许」。面板在云服务器上时，还要在云平台的安全组里放行面板端口（默认 3000）；填上 **公网 IP 或域名** 后，弹窗会给出从外面打开的网址。
- **虚拟组网**：手机用流量或在别的网络，又不想直接开放端口时用。
  - **面板自带**：点 **开启**，面板会运行 EasyTier（第一次会先下载）。在 Android 手机上安装同一版本的 EasyTier，点 **显示加入信息**，把网络名、密钥和节点填进 App 并打开 DHCP；加入后扫 **打开面板** 里的二维码。**已加入的设备** 里能看到手机。iPhone 没有官方的 EasyTier 客户端，请用下面这种方式。
  - **已装的组网软件**：电脑和手机都装好同一个组网软件（如 Tailscale）并登录同一个账号后，在这里选它的网卡并 **开启**。

不用时点 **关闭此方式**，面板回到只允许这台电脑访问。经 SSH 管理的服务器也可以用启动器命令：`remote on`、`remote off`、`remote status`、`remote https off`。

### 安全建议

- 使用强密码；面板能读写实例文件并启动进程，等同于高权限工具。
- 不要在公共电脑上保持登录状态。
- 不要把管理员密码、配置文件里的密钥和初始化令牌发给其他人或提交到仓库。
- 怀疑密码泄露或有别人登录了面板时，修改密码，或按 [忘记管理员密码](#忘记管理员密码) 重置；对方的登录会立即失效。

## 实例总览

**作用**：一眼看到所有服的状态，并做日常操作。

标题下方的「本机」一栏显示主机 CPU、主机内存和数据盘剩余空间。下面每台服务器占一行：状态后面有一句说明（例如「可以进服了」「这个服务器需要 Java 21」），右侧是对应的下一步按钮（邀请玩家、打开实例设置、查看并同意 EULA、查看控制台），再往右是启动或停止。列表右上角可以切换「全部 / 运行中 / 异常」。运行中的服务器显示进程的 CPU 和实际内存占用，旁边的细条是相对「最大内存」（给 Java 设置的堆内存上限 `-Xmx`）的比例；实际占用通常略高于这个上限，两者不是一回事。还没有实例时，页面列出一键部署、导入服务端、创建空实例三种方式。首次采样显示「采集中…」，当前系统不支持的指标显示「暂不可用」；监测失败时保留旧值并标注可能过期，可点「重试监测」。

| 列 / 区域 | 说明 |
|-----------|------|
| 名称 | 点击这一行按钮以外的任意位置（行尾有箭头）进入该实例详情 |
| 核心 | Paper、Fabric、Vanilla、Forge、NeoForge，自己上传 jar 的显示「自定义 Jar」 |
| 版本 | Minecraft 版本号（自定义导入可能为 `-`） |
| 状态 | 彩色徽章（见下表），后面跟一句现在能做什么 |
| 操作 | 需要时先给出下一步（邀请玩家、打开实例设置、查看并同意、查看控制台、去迁移），再是当前可执行的启动/停止；重启、强制停止、删除收在「更多操作」中 |

实例状态和指标每 5 秒自动刷新，切到其他标签页时暂停。页面右上角有 **一键部署**、**导入服务端** 和 **创建空实例**（自己上传 `server.jar` 时用）；还没有实例时这三项改为列在页面中间。刷新失败时保留上次的数据，并提示可能已过期。

### 实例状态

| 界面显示 | 含义 | 你可做的 |
|----------|------|----------|
| 已停止 | 没有运行中的 Java 进程 | 可启动 |
| 启动中 | 正在拉起进程 | 等待 |
| 运行中 | 服务端已启动 | 可进游戏、发控制台命令 |
| 停止中 | 正在结束进程 | 等待 |
| 已崩溃 | 进程异常退出 | 看控制台日志排错 |
| ▲ 待迁移 | 旧版外部实例，尚未接管 | 见 [旧版外部实例接管](#旧版外部实例接管) |

**按钮逻辑**

- **启动**：仅在非「运行中」时可用。
- **停止**：仅在非「已停止」时可用。
- **重启**：任意时刻可点（会先停再启），确认弹窗会提示中断风险。
- **强制停止**：立即结束进程，可能损坏世界，需确认；建议先试普通停止。
- **删除**：须先停止实例；需要输入实例名称确认，会删除面板里的记录和该实例目录的全部文件，不可恢复。旧版外部目录不会被访问或删除。

## 一键部署（表单说明）

从 Mojang / Paper / Fabric / Forge / NeoForge 下载文件并创建实例。下载慢或连不上时，可以到 [下载来源](#下载来源) 换成国内镜像。

| 字段 | 说明 |
|------|------|
| 实例名称 | 在总览中显示的名字，默认「我的服务器」 |
| 核心类型 | Paper / Fabric / Forge / NeoForge / Vanilla；默认选中新手推荐的 Paper |
| 游戏版本 | 选定核心后自动加载版本列表，并默认选中最新正式版 |
| Paper 构建版本（可选） | 仅 Paper；留空时使用最新构建（优先稳定版） |
| Loader / Forge / NeoForge 版本（可选） | 模组加载器版本；Fabric 另有 Installer 版本。留空时使用最新稳定版 |
| JVM 设置 | 填初始内存、最大内存，选择优化方案；高级区可填附加参数，见 [JVM 配置器](#jvm-配置器) |
| Java 运行时 | 默认「系统默认 Java」，也可点「重新扫描」后选择其他已安装的 Java，见 [Java 运行时](#java-运行时) |
| Minecraft EULA | 默认不勾选；必须勾选「我已阅读并同意 Minecraft EULA」才能开始部署，启动时写入 `eula=true` |

页面右侧的新手指引说明各核心的适用场景和部署后的进服步骤。

点击 **「开始部署」** 后出现进度条与文字说明（下载、解压、安装等），完成后 **自动跳转** 到新实例页。

面板默认同一时间只执行一个部署或导入任务，其余任务显示为「排队」，这是正常状态，不要重复提交；排队位置也满时页面会提示稍后重试。单个任务执行超过 30 分钟会失败。这些上限可在 [配置说明](configuration.zh-CN.md) 中调整。

**Forge / NeoForge 提示**：会下载官方安装器并执行安装，时间可能较长，请勿关闭面板。

### JVM 配置器

一键部署、导入、创建空实例和实例设置使用同一个配置器。基础界面并排填初始内存（`Xms`）和最大内存（`Xmx`），初始内存下面有 2 / 4 / 6 GB、最大内存下面有 8 / 10 / 12 GB 常用档位（超出本机内存的不显示），旁边（窄时在下面）选优化方案。内存框右侧的小箭头（或在框里按 ↑ ↓）一次加减 1 GB。初始内存没改过时按优化方案自动取值，改过之后就不再跟着最大内存变。「高级 JVM 参数」折叠区里是附加参数和最终参数预览；填了附加参数或参数有错误时会自动展开。

- **兼容优先**：只生成内存参数，初始内存自动取 1 GiB（最大内存更小时取最大内存）。
- **G1 均衡**：启用 G1、并行引用处理和 200 ms 暂停目标，仅在已识别 Java 8 / 17 / 21 / 25 时可选。切到这个方案时初始内存自动改成和最大内存相同，之后跟着最大内存变；也可以自己再改。
- **Paper Aikar**：仅 Paper 与已识别 Java 8 / 17 / 21 / 25 可选，初始内存锁定为和最大内存相同；低于 6 GiB 会提示警告。界面同时显示冻结版本、复核日期和 PaperMC 官方来源。

推荐最大内存约为本机总内存的 25%，按 512 MiB 向下取整，通常不低于 2 GiB、不高于 8 GiB，并为系统预留至少 2 GiB；低内存机器可降到 1 GiB，读不到内存时回退 2 GiB。

资源偏高、Java 版本未验证和 Paper 内存不足只是警告。下面这些会阻止保存：未闭合的引号、内存参数重复或 `Xms` 大于 `Xmx`、互相冲突的 GC 参数，以及由面板负责的启动参数（`-jar`、classpath、模块启动、`@argfile`、`nogui` 等）。

## 导入已有服务端（表单说明）

页面提供三种方式，都会复制出一个新的托管实例，不会让实例直接在原目录运行。

还没选好来源时，页面上只有来源这一栏。上传并检查完（或在 imports 里选中一个能导入的文件夹）后，右边（窄屏时在下面）出现 **导入设置**：实例名称、面板识别出的服务端（核心和版本）、要用的 Java 和最大内存，以及 EULA 勾选。核心类型、Minecraft 版本、Java 运行时和 JVM 设置收在 **修改设置** 里，识别结果对就不用打开。Java 版本不符、没有可用的 Java、JVM 参数有错误或警告、`user_jvm_args.txt` 用不了时，**修改设置** 会自动展开；换到别的来源时重新收起。还不知道 Minecraft 版本时（例如上传 ZIP，版本要到导入时才识别），摘要会提醒无法确认 Java 是否合适，可以在 **修改设置** 里填上版本。

### 上传文件夹

在浏览器里直接选服务端所在的文件夹。服务端在面板这台电脑上，或者在你打开面板网页的另一台电脑上，都可以用：

1. 在原控制台正常停止服务器，确认世界保存完成。运行中的服务器会占用 `session.lock` 等文件，浏览器读不出来。
2. 打开侧栏 **导入服务端 → 上传文件夹**，点 **选择文件夹**，选整个服务端所在的那一层（里面有 `server.jar` 或 `run.bat`）；也可以把文件夹直接拖进框里。浏览器会问是否把这些文件上传到这个网站，点上传。
3. 点 **上传并检查**。浏览器分批把文件传给面板，进度条显示已传的文件数，中途可以点 **取消上传**。传完后面板检查启动文件，并读取根目录的 `user_jvm_args.txt`，规则同下面的「从 imports 文件夹复制」。
4. 核对 **导入设置** 里的实例名称和识别结果，需要时点 **修改设置** 改核心类型、版本、Java 或内存，然后点 **确认设置并导入**。

- 面板只收到文件内容和它们在文件夹里的相对路径，拿不到也不记录这个文件夹在你电脑上的位置。原文件夹不会被改动。
- 上传的文件先放在数据目录的 `uploads` 里，确认导入时整个移进新实例，不会再多占一份空间。
- 上传并检查过的文件夹保留 30 分钟，在同一个浏览器标签页里刷新可以继续确认；取消、过期或面板重启都会删掉它。上传到一半刷新页面，需要从头再传。
- 浏览器只上传文件，空文件夹不会带过来；服务端启动时会自己建需要的空文件夹。
- 文件数和总大小的上限同「从 imports 文件夹复制」，数据盘放不下时一开始就会提示。
- 某个文件读不出来时，页面会写出是哪个文件，通常是原服务器还在运行。
- 手机浏览器大多不能选文件夹，不显示这个选项；这时用上传 ZIP，或从 imports 文件夹复制。

### 从 imports 文件夹复制

适用于服务端已经在面板所在的电脑上、但当前不由面板管理的情况，例如通过 SSH 管理的服务器（浏览器在另一台电脑上，选不到服务器上的文件夹），或者服务端特别大。

这个方式平时不在方式切换里：在「上传文件夹」下方点 **「改为从 imports 文件夹复制」** 切过来；`imports` 里已经放了文件夹，或者浏览器选不了文件夹（例如手机）时，它会直接列出来。步骤：

1. 在原控制台正常停止服务器，确认世界保存完成。
2. 把完整服务端目录复制到 `imports` 文件夹，一个服务端一个文件夹，直接放在 `imports` 下。页面上写着这个文件夹在面板电脑上的完整路径（默认是面板所在文件夹里的 `data/imports`），点 **复制路径** 可以复制下来。不要只复制 jar；世界、插件、模组和配置都应一并复制。服务端在你自己的电脑上又很大时，用 SFTP 工具（如 WinSCP、FileZilla）或 rsync 传到这个文件夹，传断了能续传；经浏览器上传文件夹不能续传。
3. 打开侧栏 **导入服务端 → 从 imports 文件夹复制**，在「imports 里的服务端」里选它；刚复制进去的先点 **刷新**。每一行写着面板识别出的核心和版本、启动用的 jar，以及有没有 `user_jvm_args.txt`；还没认出启动文件的写「导入时再检查」，不能导入的写着原因，不能选。
4. 若根目录有 `user_jvm_args.txt`，面板会自动沿用里面的参数，摘要的内存一栏写「来自 user_jvm_args.txt」，**修改设置** 里 JVM 设置上方提示「已检测到配置文件，已自动配置」；不想用就在那里点 **取消**，参数回到沿用之前的样子，之后还能点 **重新应用**。文件解析失败时不会沿用，提示里写明原因。换到别的文件夹时，上一个文件夹带来的参数会还原。
5. 核对 **导入设置** 里的实例名称和识别结果，需要时在 **修改设置** 里改，点 **复制并导入**。核心类型和版本会按启动文件名自动填好（例如 `forge-1.12.2-….jar` 会填 Forge 和 1.12.2），认错了可以改；核心类型保持 **自动识别** 时以面板的识别结果为准。
6. 等待任务完成并跳转到实例页，先检查文件和配置，再从面板启动。

> 不要在原服务器仍运行时复制。面板无法锁定外部进程，运行中复制可能得到不一致的世界数据。

面板只列出 `imports` 下的第一层文件夹，不能选择电脑上的其他位置。复制前会检查：

- 文件夹里没有符号链接、目录联接和设备文件之类的特殊文件；
- 它不是另一个面板实例的目录（根目录有 `.mystry-instance.json`）；
- 文件数不超过 20 万、总大小不超过 100 GiB（可在 [配置说明](configuration.zh-CN.md) 中调整），目标磁盘空间足够。

原文件夹和 `imports` 里的副本都不会被面板修改或删除；确认新实例运行正常后，可以自行删掉 `imports` 里的副本。

### 上传 ZIP

| 字段 | 说明 |
|------|------|
| 安装包（`.zip`） | 必选；默认最大 512 MiB，解压后的条目数和总大小也有上限 |
| 实例名称 | 预检成功后填写，同部署 |
| 核心类型 / Minecraft 版本 | 在 **修改设置** 里，可选；用于实例展示和 Java 版本提示，启动文件仍由面板探测 |
| JVM 设置 | 在 **修改设置** 里，使用统一配置器；ZIP 里有 `user_jvm_args.txt` 时自动沿用，可点 **取消** |
| Java 运行时 | 在 **修改设置** 里；默认使用系统默认 Java，也可选择面板已探测到的其他 Java |
| Minecraft EULA | 默认不勾选；原服务端的 `eula.txt` 已同意时可保持不勾选，勾选后启动时写入 `eula=true` |

导入分两步：

1. 点 **上传并检查**：面板检查 ZIP 结构和大小，并读取根目录（或唯一顶层文件夹）中的 `user_jvm_args.txt`。
2. 核对 **导入设置**（需要时打开 **修改设置**）后点 **确认设置并导入**，这时才开始后台导入。

预检结果保留 30 分钟。在同一个浏览器标签页里刷新或离开再回来，可以继续确认；也可以点取消，立即删除上传的临时文件。过期或面板重启后需要重新上传。

导入时，如果 zip 里只有一层根文件夹，会自动展平到实例根目录；面板会自动找出服务端 jar，或现代 Forge / NeoForge 的启动参数文件。任务排队已满时页面会提示稍后重试，预检结果会保留，不必重新上传。

## 下载来源

在 **本机环境** 页可以选择面板从哪里下载文件，保存后立即生效，不需要重启：

- **官方来源**（默认）：直接连接 Mojang、PaperMC、FabricMC、Forge、NeoForge 和 GitHub，不连接任何第三方镜像。
- **国内镜像**：Vanilla、Forge、NeoForge 和版本列表使用 [BMCLAPI](https://bmclapidoc.bangbang93.com/)，frp 和 EasyTier 使用公共 GitHub 镜像。部署 Vanilla 时仍会从 Mojang 读取版本清单，镜像文件的校验值来自它。镜像失败时自动改用官方来源。

国内镜像由第三方运营，面板只使用能核对校验值的文件，校验不符会丢弃并换下一个来源。

选了国内镜像后，这些内容仍然走官方：

- Paper 和 Fabric 的服务端文件，它们没有可靠的镜像。
- Forge 和 NeoForge 安装器的部分文件，所以网络完全连不上 Mojang 时安装可能失败。
- 服务端第一次启动时自己下载的文件（如 Fabric 的依赖）。

已经下载到本地缓存的文件不会重新下载，切换来源对它们没有影响。

## Java 运行时

面板不接受手填 Java 路径。各游戏版本需要的 Java 见 [分步教程：装好 Java](tutorials.zh-CN.md#1-装好-java)。

「一键部署」和导入页会按游戏版本自动选 Java：系统默认 Java 合适就用它，否则选已装的推荐版本。你亲手改选后就不再自动改。「一键部署」里，实际要用的 Java 不是推荐版本时不能点「开始部署」，页面会说明需要哪个版本。已有实例的「实例设置」不会自动改动已保存的 Java。

选择器下方一行先显示实际要用的那个 Java 的状态：选了面板登记的某个 Java 就说它（例如「Java 21.0.5 可用」），保持「系统默认 Java」才说系统默认 Java；实际要用的 Java 不是推荐版本时，后面接着写「推荐 Java N」。推荐版本没装时，同一行再接 **「安装 Java N」** 按钮（Windows 和 Linux x64 上支持 Java 8、17、21、25）。点了先弹确认，写明从哪里下载、大约多大；下载期间进度条右边的 **「取消安装」** 可以停下并删掉下了一半的文件。面板从 GitHub 下载 Eclipse Temurin JRE（下载来源设为国内镜像时经 GitHub 镜像下载）；每个版本钉死在固定的发行版，用前按 SHA-256 校验。装到数据目录的 `runtimes/java`，加入 Java 列表并选中。下载以任务运行，可在「任务中心」查看进度；失败时可以换下载来源，或用「自己下载安装」链接。

默认使用运行面板的环境里 PATH 中的 `java`，界面显示为「系统默认 Java」；可以在同一环境中执行 `java -version` 检查它的版本。

要使用其他已安装的 Java，在「一键部署」、导入页（**修改设置** 里）或「实例设置」中的 **Java 运行时** 点「重新扫描」。选项只写主版本，同一个主版本装了不止一个时才带上路径区分；鼠标停在下拉框上可以看到所选 Java 的路径。面板只在 `JAVA_HOME` 和常见安装目录中查找，并逐个运行验证。列表中标为「不可用」的条目表示最近一次探测没有再找到它，需要重新选择。选定的 Java 在每次启动实例和执行 Forge / NeoForge 安装器前都会再验证一次。

版本不匹配时，控制台常见 `UnsupportedClassVersionError` 或无法启动。

## 实例详情

顶部显示实例名、核心、版本、状态，以及 **启动 / 停止 / 重启 / 强制停止**；左上角的「‹ 实例总览」回到总览。

### 控制台

- 实时显示服务端的输出。
- **输入命令 + 回车** 发送到服务端（与游戏内控制台一致）；下方的「常用命令」可一键发送 `list`、`save-all` 等。发出的命令会以 `> list` 这样的粗体白字记在日志里，后面紧跟服务端的回复。
- 连接断开或刷新页面后会自动重连，并先显示最近的历史输出。
- 单条命令长度和每分钟可发送的命令数有上限，超出时页面会提示，见 [配置说明](configuration.zh-CN.md)。
- 若显示「登录已失效」或「控制台连接凭证无效」，尝试 **退出登录再登录**。

### 文件管理

只能操作当前实例根目录里的文件：

| 位置 | 操作 |
|------|------|
| 顶部左侧 | **‹** 返回上级目录；路径按层级显示，点任意一级可直接跳回 |
| 顶部右侧 | **刷新**、**新建文件夹**（弹窗输入名称）、**上传** 文件到当前目录 |
| 点击文件夹 / 文本文件 | 进入文件夹，或直接打开编辑 |
| 每一项右侧「…」 | **下载**（仅文件）、**编辑**（仅文本文件）、**重命名**、**删除** |

**编辑** 会在弹窗中打开文件内容，点 **保存** 写回磁盘；大文件和二进制文件不能在线编辑。

路径相对于实例根目录。修改 `mods`、`plugins`、世界数据前建议 **先停服**。

下载由浏览器直接保存，大文件也不会占满页面内存；默认最多同时 4 个下载，繁忙时会提示「下载繁忙，请稍后重试」。需要整目录拷贝时，停服后用系统的文件管理器操作实例目录。

删除文件或文件夹统一使用确认弹窗；删除文件夹会连同其中内容一起删除，弹窗会显示路径并提示不可恢复。

### 参数配置

- 常用 `server.properties` 键按基础、多人和权限、世界、性能分组展示，开关类设置用开关切换；未收录的键保留在「高级选项」中。
- 底部悬浮栏的 **保存配置** 保存后需 **重启实例** 才能生效（页面有说明）。
- 页面会标记未保存的修改，离开页面或关闭标签页前会确认是否放弃。
- 与直接编辑 `server.properties` 文件等价。
- 1.13 及更早的服务端用数字保存难度和游戏模式。表单照常显示名称，保存时写回数字。
- 服务器简介等文字里的中文写入文件时会变成 `\uXXXX`，新旧版本的服务端都能正确读取。之前已经变成乱码的简介不能自动恢复，要重新填写一次。

### 联机

要让玩家加入这个服，打开侧栏 **部署与维护** 里的 **联机**，先在左上角选实例，再用旁边的分段切换 **直接连接**、**虚拟局域网** 和 **frp 穿透**，一次只显示一种；换过去不会关掉其他方式里已经保存的设置。服务器加载完世界后，实例控制台上方也会提示「服务器已启动，现在可以进服了」，点 **邀请玩家** 可以直接到这一页；不想再看到这条提示就点它末尾的 **×**（不再提示）。面板只转发这个实例的游戏端口，不会把管理页面暴露出去，也不用填写任何程序路径。

页面右侧是 **指引** 栏：各种穿透模式的区别、连不上时逐项检查什么。用熟了可以点 **×** 关掉，之后点 **显示指引** 再打开；这个选择记在当前浏览器里。窄屏时指引排在页面最下面。

- **直接连接**：玩家直接连这台电脑的地址。玩家和这台电脑连着同一个 Wi-Fi 或路由器，或者这台电脑有公网地址时用。页面直接显示 **同一网络的加入地址**，点 **复制** 发过去即可，不用安装或设置任何东西。
  - 这是内网地址：只有和这台电脑连着同一个路由器或 Wi-Fi 的玩家能用，其他网络的玩家用它连不上。地址下面紧跟着 **改用虚拟局域网** 和 **填写公网地址** 两个出路。
  - 服务器第一次启动时，Windows 可能会弹窗询问是否允许 Java 访问网络，要选「允许」。
  - 电脑有多个地址时，先试 `192.168` 开头的那个。
  - 这台电脑有公网 IPv6 时，下面还会多出一个 **IPv6 加入地址**，不在身边的玩家如果也有 IPv6 可以直接用它加入；连不上时请在路由器里只放行游戏端口，不要整个关掉路由器的 IPv6 防火墙。
  - 这台电脑有公网 IP（云服务器、机房）时，点加入地址下面的 **填写公网地址**，填上公网 IP 或域名，页面会给出 **公网加入地址**，指引栏里会多出一份检查清单；最常见的原因是云平台的安全组没有放行游戏端口。游戏端口和面板端口是两回事：玩家进服只需要放行游戏端口。

- **虚拟局域网**：不需要自己的公网服务器。打开最上面的 **对玩家开放这个实例** 开关（点了立即生效，不用再保存），下面会出现 **让玩家加入** 三步：复制或下载 **加入说明** 发给玩家；玩家按说明运行 EasyTier；玩家在 Minecraft 里连步骤里显示的加入地址。还没装 EasyTier 时页面只显示下载按钮，装好后才出现开关。
  - Windows 上要以管理员身份启动面板，玩家也要以管理员身份运行命令，否则创建不了虚拟网卡。
  - 打洞失败时，流量经社区共享节点中转，内容用网络密钥加密。
  - **中继节点**：默认使用几个由志愿者维护的社区共享节点，它们随时可能下线，也可能离你们很远。你可以展开 **中继节点**，在「自己的中继节点」里一行填一个自己的节点（例如 `tcp://relay.example.com:11010`），也可以取消「同时使用社区共享节点」只用自己的，再点 **保存中继节点**。改了节点要把新的加入说明重新发给玩家。
  - **直连端口**：面板会额外开一个直连端口（显示在页面最下面），有 IPv6 或在同一局域网的玩家可以不经中转直接连上。
  - **Windows 防火墙**：面板会自动添加放行规则，只放行虚拟地址上的游戏端口和直连端口（直连端口只对面板启动的 EasyTier 程序生效），关掉时自动删除；面板异常退出留下的规则会在下次启动时清掉。如果你以前在 Windows 防火墙弹窗里阻止过 Java，需要先在「Windows Defender 防火墙 → 高级设置 → 入站规则」里删掉 Java 的阻止规则。
  - 加入说明里有网络密钥，拿到的人都能进入这个虚拟局域网并连上游戏端口，不要公开发出去。
- **frp 穿透**：需要一台自己的 frp 服务器（地址、端口和令牌）。还没有 frp 服务器时，页面先显示添加表单。添加以后选好服务器、穿透模式和端口，点 **保存并开放**；之后用最上面的 **对玩家开放这个实例** 开关打开或关闭，**穿透设置**（连同 **添加 frp 服务器**）收进折叠区。删除按钮在服务器下拉框旁边，删的是当前选中的那台。
  - 穿透模式选 **公网端口** 时：玩家在 Minecraft 的多人游戏里直接添加页面上的加入地址，不用装 frp。
  - **STCP 中转** / **XTCP 打洞**：按 **让玩家加入** 里的步骤，复制或下载 **玩家配置** 发给对方。对方用官方 frpc 运行后，连接自己电脑上的 `127.0.0.1` 和「玩家本机端口」。STCP 经 frp 服务器转发；XTCP 是点对点直连，延迟更低，但部分网络打不通。这个文件里有令牌，只发给要加入的玩家。

如果面板连不上 GitHub、下载客户端失败，点下载按钮下方的 **手动安装**，会显示官方压缩包的文件名和 SHA-256：用任意设备从官方页面或镜像下载同名文件，再点 **上传压缩包**。只有 SHA-256 一致的文件才会被安装。

先启动实例，联机才会打开。如果游戏配置里的 `server-ip` 写成了某一块网卡的地址，要先清空它，否则外网连不进来。

### 备份

**立即备份** 把整个实例目录打包成一份备份（世界、配置、mods、plugins 都在里面）。服务器运行中也能备份：面板会先暂停自动保存并把世界写入磁盘，打包完再恢复自动保存，玩家不用下线；启动中或停止中时要等它完成。

| 位置 | 操作 |
|------|------|
| 顶部右侧 | **刷新**、**上传备份**（之前下载的 `.tar.gz`，校验通过才会出现在列表里）、**立即备份** |
| 每一项右侧「…」 | **下载**、**还原**、**删除** |

**还原** 前要先停止服务器。还原会用备份替换实例目录的全部文件，之后新增的文件会被删除；弹窗里的「先备份当前文件」默认勾选，会先自动生成一份「还原前自动备份」，还原错了可以再还原回来。备份会先完整校验，文件损坏或被改动时不会动实例目录。如果备份时用的服务端 jar 和现在不同（比如之后升级过版本），还原后面板里的服务端文件、核心类型和版本会一起改回备份时的值。

备份默认放在数据目录的 `backups/` 下，可用 `BACKUP_DIR` 放到另一块磁盘，见 [配置说明](configuration.zh-CN.md#数据目录)。备份只包含这个实例的文件，不包含账号和面板里的实例设置。删除实例时默认连同它的备份一起删除，取消勾选「同时删除该实例的备份」则备份留在 `backups/` 里，但不再显示在面板中；整个面板的备份见 [备份与迁移](tutorials.zh-CN.md#教程-8备份与迁移)。

### 实例设置

| 字段 | 说明 |
|------|------|
| 名称 | 可改 |
| Jar 文件名 | 相对实例目录，如 `server.jar`。Forge / NeoForge 实例这一栏换成只读的「启动文件」，显示部署或导入时面板识别出的参数文件 |
| JVM 设置 | 使用统一配置器修改内存、预设和高级参数；改后建议重启 |
| Minecraft EULA | 勾选后每次启动会写 `eula=true` 到 `eula.txt`；不勾选时保留实例目录中原有的 `eula.txt`（导入的服务端可以自带同意记录）。勾选过之后取消勾选并保存，会把它改成 `eula=false` |
| 安装路径 | 只读，显示实例目录的完整路径；由面板分配，创建后不可修改 |
| Java 运行时 | 默认「系统默认 Java」，或选择面板探测到的其他 Java；可重新扫描 |

点 **保存设置** 后页面会显示「设置已保存」或失败原因；离开页面前同样会确认是否放弃未保存的修改。

## 数据存在哪里？

实例列表、账号和任务记录在数据目录的 `panel.db`，实例文件在 `instances/<id>/`。完整结构和修改位置的方法见 [配置说明](configuration.zh-CN.md#数据目录)，备份方法见 [备份与迁移](tutorials.zh-CN.md#教程-8备份与迁移)。

删除实例会删掉该实例目录的全部内容。旧版外部目录不由面板访问或删除。

## 旧版外部实例接管

旧版外部实例是数据库中仍记录旧目录、但尚未迁入面板托管根目录的实例。面板不会访问旧目录，也不会自动搬迁或删除它。

1. 停止该实例，并停止面板服务。
2. 用操作系统的复制工具，将旧外部目录完整复制到数据目录下的 `instances/<id>`。
3. 启动面板，进入对应实例（总览中显示「▲ 待迁移」），点击 **完成迁移**。
4. 接管成功后，实例才按面板托管目录处理；旧目录仍由用户自行保留或管理。

若目标目录为空、不完整、ID 不对应或实例仍在运行，接管会失败。请不要在面板中尝试通过文件页访问旧目录。

## 常见问题

### 部署或导入一直卡住

- 页面显示「排队」时属于正常状态，会一直刷新到完成或失败。
- 检查本机能否访问外网（Mojang、Paper、Fabric、Forge 等）。在中国大陆可以试试把 [下载来源](#下载来源) 换成国内镜像。
- 看进度条的文字停在哪一步；Forge / NeoForge 安装尤其慢。
- 任务中心里会显示失败原因；面板日志里可能有更详细的错误，可用启动器的 `logs` 命令查看。

### 启动后立即退出或「已崩溃」

先看 **控制台** 上方有没有提示。面板能认出下面两种原因，并直接给出下一步：

- **还没同意 Minecraft EULA**：状态是「已停止」。点提示里的 **同意并启动** 即可；也可以在 **实例设置** 中勾选 Minecraft EULA。
- **Java 版本太新或太旧**：提示会写出这个服务器需要的 Java 版本。点 **下载 Java** 安装后，打开 **实例设置**，点 **重新扫描**，选中它，保存后再启动。

没有提示时：

1. 看控制台最后几行错误。
2. 在 **实例设置** 检查 Jar 文件名和 JVM 参数。
3. 确认使用的 Java 可用且版本匹配，见 [Java 运行时](#java-运行时)。

### 游戏连不上服务器

- 服务端是否 **运行中** 且控制台已出现 `Done`。
- `server.properties` 里 **server-port** 是否与游戏填的端口一致。
- 本机测试用 `127.0.0.1`；局域网用主机局域网 IP；云服务器用公网 IP，并在安全组里放行游戏端口。
- 防火墙是否放行 Java 或该端口。

### 提示「登录已失效」

- 重新 **登录**。
- 手动运行面板、初始化管理员失败时，确认填写的是当前配置文件里的 `SETUP_TOKEN`，并且还没有创建过管理员。

### 导入 zip 失败

- 确认是 **zip** 且不超过 512 MiB；提示超过大小限制时，换一个小一点的包或调大上限。
- 提示繁忙时，等当前上传结束后再试。
- 包内是否包含服务端 jar（不是仅客户端）。
- 包内有指向包外路径的条目时，面板会拒绝导入。

### 忘记管理员密码

在面板运行期间，在运行面板的这台电脑上执行 `reset-password` 命令：便携版 Windows 为 `.\mystryctl.cmd reset-password`，便携版 Linux 为 `./mystryctl reset-password`，源码版为 `.\PanelManager.cmd reset-password` 或 `./PanelManager.sh reset-password`。窗口会显示一个新的随机密码，只显示一次。请直接在终端窗口里运行：输出被重定向到文件或通过管道传出时，命令会拒绝执行，旧密码继续有效。登录后点左下角的钥匙图标改成自己的密码。

重置密码会让所有浏览器和设备上的登录失效，包括你正在用的；重新打开面板，用新密码登录即可。

手动运行面板、没有使用启动器时没有这个命令。需停服后自行处理数据目录里 `panel.db` 的 `users` 表，或删除 `panel.db` 重新初始化（会丢失实例注册信息，磁盘上的实例文件仍在）。重新初始化时必须重新配置 `SETUP_TOKEN`。
